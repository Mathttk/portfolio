Portfólio profissional desenvolvido para apresentar minhas habilidades em desenvolvimento front-end, meus projetos e os serviços que ofereço como freelancer.

**[🌐 Acessar Portfólio Online](https://mathttk.github.io/portfolio/)**

## Sobre o Projeto

Este portfólio foi desenvolvido com o objetivo de apresentar meus trabalhos como desenvolvedor web freelancer, com foco na criação de sites responsivos, landing pages e aplicações web.

O site possui uma interface moderna, navegação adaptada para dispositivos móveis, apresentação dos projetos desenvolvidos e canais de contato para potenciais clientes.

## Tecnologias Utilizadas

- HTML5 — Estrutura semântica das páginas
- CSS3 — Estilização, responsividade e efeitos visuais
- JavaScript — Interatividade e navegação
- Git e GitHub — Controle de versão
- GitHub Pages — Hospedagem e publicação

## Funcionalidades

- Layout responsivo para computadores, tablets e celulares
- Menu de navegação mobile
- Recursos de acessibilidade na navegação
- Apresentação de projetos com demonstrações online
- Seção de contato
- Metadados de SEO e imagem de compartilhamento Open Graph
- Favicon SVG personalizado

## Projetos em Destaque

### StockFlow — Sistema de Gestão de Estoque e Vendas

Aplicação web de gestão de estoque e vendas desenvolvida a partir de uma necessidade comercial real de uma distribuidora de bebidas.

A versão pública utiliza dados fictícios e demonstra funcionalidades de cadastro de produtos, controle de estoque, vendas, despesas e acompanhamento financeiro.

**[Demonstração Online](https://mathttk.github.io/stockflow-demo/)** | **[Repositório](https://github.com/Mathttk/stockflow-demo)**

### ClimaPro — Landing Page Responsiva

Landing page desenvolvida para uma empresa fictícia de serviços de climatização.

O projeto inclui apresentação de serviços, navegação mobile, recursos de acessibilidade e formulário de solicitação de orçamento integrado ao WhatsApp.

**[Demonstração Online](https://mathttk.github.io/climapro/)** | **[Repositório](https://github.com/Mathttk/climapro)**

## Como Executar Localmente

Clone o repositório:

```bash
git clone https://github.com/Mathttk/portfolio.git
```

Acesse a pasta:

```bash
cd portfolio
```

Abra o arquivo `index.html` no navegador ou utilize um servidor local, como a extensão Live Server do VS Code.

Não é necessário instalar dependências ou executar um processo de compilação.
