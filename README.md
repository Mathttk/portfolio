## About the Project

This portfolio was built to present my work as a freelance web developer, with a focus on responsive websites, landing pages, and web applications.

The website features a clean, modern design, responsive layouts, project showcases, and contact options for potential clients.

## Technologies

- HTML5 — Semantic page structure
- CSS3 — Styling, responsive layouts, and visual effects
- JavaScript — Interactive navigation and user experience
- Git & GitHub — Version control
- GitHub Pages — Website hosting and deployment

## Features

- Responsive design for desktop, tablet, and mobile devices
- Mobile navigation menu
- Accessible navigation controls
- Featured projects with live demonstrations
- Contact section
- SEO metadata and Open Graph sharing image
- Custom SVG favicon

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Mathttk/portfolio.git
```

Open the project folder:

```bash
cd portfolio
```

Open `index.html` in your browser or use a local development server, such as VS Code Live Server.

No build process or package installation is required.
